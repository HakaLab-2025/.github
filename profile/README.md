## 🚀 Quiénes somos

En **HakaLab** construimos sistemas de calidad impulsados por IA que convierten la entrega de software en **entrega continua de valor**. Combinamos automatización avanzada, inteligencia artificial y control humano con trazabilidad auditable para que la calidad sea **continua, predecible y gestionable**, reduciendo riesgos técnicos y de negocio.

Somos **dueños de nuestro stack**: un ecosistema propio de productos de calidad —desde el motor de automatización hasta la gestión de pruebas en Jira— que adaptamos al cliente, no al revés.

## 🧩 Ecosistema de Productos

Nuestro ecosistema cubre todo el ciclo de vida de la calidad, organizado en tres capas. **[Ver todos los productos →](https://www.hakalab.com/productos)**

### ⚙️ Haka Core Suite — _Automatización de extremo a extremo_

| Producto                                                                     | Qué hace                                                                                                                                                                                   |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **[Haka Automation Engine](https://www.hakalab.com/haka-automation-engine)** | Framework de automatización sobre Playwright + Behave (BDD/Gherkin), con un catálogo de +1800 pasos preconstruidos y self-healing con IA. El motor del ecosistema, listo para CLI y CI/CD. |
| **[Haka Agentic IDE](https://www.hakalab.com/haka-agentic-ide)**             | Aplicación de escritorio que le da rostro agéntico al Engine: construcción visual de pruebas y asistencia de IA, para perfiles no-code y expertos por igual.                               |
| **[HakaPath](https://www.hakalab.com/hakapath)**                             | Extensión Chrome/Edge que genera localizadores XPath y CSS con IA, con indicador de robustez y exportación a Page Object Model multi-lenguaje.                                             |
| **[Haka Mobile Studio](https://www.hakalab.com/haka-mobile-studio)**         | App de escritorio para inspeccionar, grabar, reproducir y exportar pruebas móviles (Android/iOS) sobre Appium/ADB, con IA opcional y sin lock-in de código.                                |

### ⚡ Productivity — _Aceleración del día a día de QA_

| Producto                                           | Qué hace                                                                                                                                                                               |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **[HakaBoost](https://www.hakalab.com/hakaboost)** | Framework de agentes de IA para calidad, embebido como side panel en **Jira Cloud** y **Azure DevOps**: mejora historias, diseña pruebas y crea tests vinculados sin salir del ticket. |
| **[HakaBuddy](https://www.hakalab.com/hakabuddy)** | App de escritorio que centraliza pruebas manuales y automatizadas (Playwright): evidencia rica, reportes PDF/HTML/Xray y publicación de suites a CI/CD.                                |

| **Cassini**                                               | Plataforma de observabilidad que centraliza y visualiza en tiempo real los resultados de ejecuciones automatizadas, con dashboards por equipo, empresa y proyecto. |
